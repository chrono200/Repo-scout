# Repo Scout

A Termux-friendly GitHub reconnaissance and discovery CLI for exploring profiles, repositories, projects, and GitHub API data from the command line.

## Project

Repo Scout is a command-line project intended to make GitHub discovery and reconnaissance accessible from a terminal, including Android devices running Termux.

## Installation

See the project files and release assets for the current installation instructions. The packaged archive currently available in this repository is:

- [Repo-Scout-v1.1-fixed.zip](Repo-Scout-v1.1-fixed.zip)

## Usage

Consult the included project documentation and scripts for supported commands and options. Do not assume commands or capabilities that are not implemented in the current release.

## Compatibility

Designed with Termux and command-line use in mind.
